# Verdant — IoT Smart Greenhouse

Учебный проект веб-панели для мониторинга и управления умной теплицей.

**Автор:** Темирлан Эшимбаев  
**Технологии:** HTML5, CSS3, JavaScript, Chart.js, localStorage, GitHub Pages.

## Что есть в проекте
- Главная страница с описанием системы.
- Dashboard с KPI, состоянием зон и журналом событий.
- Три зоны выращивания: Tomatoes, Cucumbers и Greens.
- Симуляция шести типов датчиков с обновлением показаний.
- Manual / Auto Mode и управление насосом, вентилятором, фитолампой, увлажнителем, обогревателем и форточкой.
- Защита насоса при критически низком уровне воды.
- Alerts, журнал действий, Risk Score и рекомендации.
- Четыре графика Chart.js на странице аналитики.
- Настройки порогов, тёмная тема, экспорт JSON и сохранение данных в localStorage.
- Адаптивная верстка для компьютера, планшета и телефона.

## Запуск
Откройте папку в Visual Studio Code и запустите `index.html` через расширение Live Server. Для графиков Chart.js и шрифтов требуется интернет; основные страницы и симулятор работают локально.

## Публикация на GitHub Pages
1. Загрузите содержимое папки в репозиторий `iot-smart-greenhouse`.
2. Откройте **Settings → Pages**.
3. В разделе Build and deployment выберите **Deploy from a branch**.
4. Укажите ветку `main` и папку `/(root)`, затем нажмите Save.

## Важно
Показания датчиков демонстрационные и генерируются в браузере. Физические датчики, ESP32, MQTT и сервер в обязательную версию не входят. Пороговые значения учебные, не универсальные агрономические нормы.
